发现的三个实质问题已在生产适配器处理：BaoStock `get_data()`依赖pandas已删除的append，改为逐行读取；行业分页超时可能留下2000行且后续查询拿到错位数据，必须校验结束状态和字段并重建会话；部分资产负债率数量级异常，例如美的返回0.006117而权益乘数2.574997对应约0.61165，生产不使用这些季频负债率字段，也不猜测“乘100修复”。

原始探测在 `exports/value-probe`、`exports/value-probe-fixed`。早期脚本暴露分页错误，不能把探测文件夹所有CSV都视为成功数据；修订脚本现已检查分页结束错误。生产结果另有不可变观测及原始响应归档。

进一步尝试细分行业：申万历史下载出现TLS证书链错误，改用系统信任链请求得到HTTP508；乐咕三级页面结构不匹配；巨潮批量行业变更未取得预期字段。这些均未绕过证书或字段校验。C35、C38混含强周期业务，默认暂不覆盖。饮料大类仍有不同主营，报告把细分主营可比性列为未知，展示同行成员及质量指标，不声称已完成细分验证。
